  - The engine sets status `bisecting` and `verifying` through `progress`. The API sets `done` or `failed` when it stores the result.
  - `Diagnoser(reader=, runner=, sink=, fixer=, settings=)`. `fixer` is a `fd_engine.verify.StepFixer`; S1 ships the OpenAI-backed one next.
  - `diagnose` raises `ReplayUnavailableError` (code `replay_unavailable`, retryable) when every replay in a check errored, and `CheckBudgetError` (code `check_budget_exceeded`). Store the code as the diagnosis `error_code`.
